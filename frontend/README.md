# ProcessTwin AI Frontend

React, TypeScript ve Vite tabanli native frontend uygulamasidir.

## Komutlar

```bash
npm run dev
npm run build
npm run lint
npm run test
```

## Kapsam

- Ilk ekran operasyon paneli iskeletidir.
- Routing altyapisi `react-router-dom` ile kuruludur.
- Tasarim kurallari `src/styles` ve component CSS dosyalari altinda tutulur.
- Inline style kullanilmaz.
- Ayni selector, mevcut tanimi guncellenmeden dosyanin altinda yeniden acilmaz.

## Sonraki UI Paketleri

ECharts ve Cytoscape.js, ilgili chart ve topoloji ekranlari gelistirilirken eklenecektir. Bu gorevde minimum React/Vite kurulumu sabitlenmistir.
